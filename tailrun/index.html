Run commands from your browser

Tailrun runs commands on a computer you control. You can use it from a phone or another computer. It shows the output as each command runs. It also keeps the logs and files for later.

Run runner.py on a computer connected to Tailscale. Enter that computer's /run address below. The public website holds no private jobs. Only people with access to your Tailscale runner can see them.
