How to use it

  1. Open any page on Hacker News.
  2. Run Dark mode toggle from your bookmarks to turn dark mode on.
  3. Run it again to restore the page’s original appearance.

Currently supports Hacker News, including threads, forms, and help pages. Run it again after navigating or reloading. Other sites show a notice and keep their appearance. The saved bookmarklet works offline and makes no network requests.
