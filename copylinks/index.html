Usage

  1. Use Copy Links to copy every unique page and asset URL as tab-separated values.
  2. Or select a passage and use Copy URL + Text Fragment to copy a link that highlights it.
  3. With no selection, Copy URL + Text Fragment copies the current page URL.
  4. Paste into a spreadsheet, text editor, or your notes.
