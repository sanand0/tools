# Wallhop

Bookmarklet to open the current page through Wallhop for one-off paywall-free reads.

Open [the Wallhop bookmarklet page](./index.html) and drag the **Wallhop** button to your bookmarks bar. Open an article, then click the saved bookmark to read it through [Wallhop](https://wallhop.io/).

The bookmarklet prefixes the full current URL with `https://wallhop.io/`, preserving its scheme, path, query, and fragment. For example, `https://example.com/article` becomes `https://wallhop.io/https://example.com/article` in the same tab.

Wallhop is intended for one-off articles shared with you. As its site recommends, subscribe to publications you read regularly.
